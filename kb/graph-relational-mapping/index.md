# Graph-Relational Mapping

This guide details graph database query conventions, relational mappings, and knowledge representations under the Panorama architecture.

## Core Modules
- **Trellis**: Graph-based knowledge graph storing core entities and relations.
- **Granite**: Handles graph-relational mappings, converting relational specifications to node-link paths.
