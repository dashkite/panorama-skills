# Application Flow Graph

This guide defines processing flow graphs, event routing, and state transition specifications evaluated by Malibu under the Panorama architecture.

## High-Level Execution Flow
Rather than writing procedural application controllers, Panorama applications declare state transitions and event routings in a flow graph.
- **Malibu**: Evaluates the declarative application flow graph, mapping events to transitions and coordinating distributed executions.
