# Routing & Page Management

This guide details page layouts, views orchestration, and application routing patterns within the Panorama architecture.

## Core Modules
- **Monterey**: Resolves URL patterns to resource locators and controls page transitions.
- **Krypton**: Manages page hierarchies, layout setups, and document rendering.
