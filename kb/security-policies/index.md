# Security Policies

This guide details rules, enforcement domains, and authorization checks specified for Panorama applications and evaluated by Enchant.

## Enforcement Philosophy
Security policies are declared in the application specification and validated at the edge and intermediary nodes:
- **Specification Validation**: Ensuring policies follow security schemas.
- **Rule Evaluation**: Checking request contexts against security rules.

> *This article is currently a baseline stub. Policy configuration formats, encryption keys handling, and validation rules will be added in subsequent updates.*
