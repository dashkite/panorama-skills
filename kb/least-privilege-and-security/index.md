# Least Privilege & Security

This guide outlines security policies, encryption, and context isolation conventions within the Panorama architecture.

## Core Modules
- **Enchant**: Evaluates caching and security policies for applications.
- **Runes, Cobalt, Guardian**: Implements least-privilege authorization policies and context isolation between running applications.
